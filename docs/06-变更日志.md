## v4.2 · 2026-11-07（P0 安全稳健批次）

**背景**：部署到 DEPLOY_HOST 并把端口改成 `0.0.0.0:8770` 内网直连后，
任何能访问该端口的人都能读到全部监控数据；同时 `audit.jsonl` 只追加不轮转，
上游异常时各页提示不一致甚至白屏。本批一次修掉三项。

### 新增

| 项 | 实现 | 为什么 |
|---|---|---|
| HTTP Basic Auth | `server.py` 的 `access` 配置 + `Handler._guard()`，覆盖 GET/POST/HEAD/OPTIONS；`hmac.compare_digest` 比对；`/api/ping` 免认证 | 零依赖收紧暴露面，不引入 nginx/额外容器；健康检查必须放行否则容器起不来 |
| 审计日志轮转 | `audit_rotate`（默认 5 MB × 5 份），`LOCK` 内先滚 `.1/.2/...` 再追加 | 长期运行不会吃满磁盘；与只读根 + `/data` 卷兼容 |
| 统一错误态 | `showGlobalError / clearGlobalError / noteRpcFailure`，`rpc()` 规范化网络错误与 401，`boot()` catch 展示卡片 | 上游不可达时给出实例/失败方法/原因/重试，而不是空白页 |

### 配套改动

- `config.json` 新增 `access`（本地 `off`、远程 `basic`）与 `audit_rotate`；
  模板 `deploy/config.docker.example.json` 同步。
- 三个测试脚本支持环境变量 `BASIC_AUTH`，用 CDP `Network.setExtraHTTPHeaders` 给文档与 XHR 统一附加凭据；
  Chrome 启动参数统一加 `--no-proxy-server`（本机企业代理会拦内网 IP）。
- 冒烟新增断言「全局错误条在数据正常时保持隐藏」→ 基线从 19 升到 **20**。
- `docs/07-页面迭代路线图.md` 新增（批次清单 + 每轮 SOP + 状态表），P0 标记完成。

### 实测

- 未认证访问 `/`、`/api/meta`、静态资源、POST → 401；错误口令 → 401；带凭据 → 200；`/api/ping` → 200。

### 修复

1. **`user.login` 参数名的错误回退**（严重）
   原实现：先试 `{user}`，失败后试 `{username}`。
   后果：4.0 返回 `unexpected parameter "username"`，把真正的"密码错误"覆盖掉；
   且多消耗一次失败计数，加速账号锁定。
   现在：按 `apiinfo.version` 精确选字段，**失败一次即返回**，错误原文透传。
2. **5.5 的字段名判断遗漏**
   原判断 `ver.startsWith("5.4")` 只覆盖 5.4。5.5 起同样是 `username`。
   现在：`major > 5 || (major == 5 && minor >= 4)`。
3. **主机详情横幅永久卡在"查询中…"**
   原实现按 `lastData` 是否为空判断，导致"查完确实没有历史"也显示"查询中…"。
   现在：新增 `S.hd.probed` 标志，区分「查询中 / 查到时间 / 查完无结果」三态。
   实测 7.0 的 Zabbix server（14 项异常）现在正确显示"前 10 项均未查到历史数据"。
4. **多序列统计单位串台**
   原实现用第一条序列的单位格式化全部统计值，出现"区间峰值 76 °C"（实为湿度 76%）。
   现在按单位分组分别格式化，双单位显示为 `23.9 °C / 76.0 %`。
5. **监控项表 `key_` 挤压数值列**
   未设 `table-layout:fixed` 时长 key 把数值列压成一条线。已加 fixed + 省略号。
6. **拓扑首屏字小（实测 29%）**
   原逻辑把 1362×914 的图按高度塞进 540px 容器。改为按宽度铺满（最少 55%）+ `overflow:auto`。
7. **拓扑 SVG 居中留白**
   `preserveAspectRatio` 默认居中等比缩放，导致左上留空。改为 `xMinYMin meet` + 显式像素宽高。
8. **手工连线不生效**
   只调 `paintTopo(S.topo.model)` 未重建模型，新边不在模型里。改为 `renderTopoPage()`。
9. **删除连线的比较写反**
   `![a,b] === [a,b]` 恒为假，导致删不掉。改为比较排序后的 `a|b` key，并引入 `plan.hidden[]`，
   避免删掉推断边后下次重算又回来。
10. **测试脚本两处误报**
    正则多转义（`/2\\s*项已选/`）、图例未等绘制完成就断言。已修正并在断言前轮询等待。

## v4.2 · 2026-10-27（窄屏适配）

用户反馈窄屏（截图约 830px）下布局塌陷。根因有四个，都不是"字太小"这类表面问题：

### 修复

14. **顶栏品牌区逐字换行，把 56px 的栏高撑破**
    `.bt/.bs` 没有 `white-space:nowrap`，flex 收缩时退化成竖排
    （"运维监控控制台"被拆成一列单字），溢出部分直接盖住下方页签。
    现在：品牌区 `flex:0 0 auto` + 文案 `nowrap` + 省略号，只缩不折。

15. **表格撑破 body 造成整页横向滚动（连带顶栏错位）**
    表格直接放在 `.card` 里，没有滚动容器。窄屏下 `table-layout:fixed` 的固定列宽
    超过容器，td 把 body 撑宽；而 `position:sticky` 的顶栏只有视口宽，
    横向滚动后右侧表格内容会"穿过"顶栏——截图里看到的"内容压在导航上"就是这个。
    现在：新增 `.tw` 滚动容器包住问题表与主机表，`#hdItemBox/#hdTrigBox/#hdProbBox`
    也补了 `overflow-x:auto`。溢出只在卡片内滚动，body 永不横向滚动。

16. **主机详情两栏在窄屏折不开**
    `index.html` 用了内联 `style="grid-template-columns:minmax(0,1fr) 320px"`，
    内联样式优先级高于媒体查询，`@media(max-width:1180px){.split{1fr}}` 完全失效。
    830px 下仍是"主栏 + 320px 侧栏"，主栏被压到 400px，
    于是 key_ 压到数值列上、状态列溢出卡片。
    现在：改为 `.split.hd` 类，媒体查询里同名覆盖。

17. **"确认"列竖排**：56px 装不下"未确认"，改成 66px + `nowrap`。

### 新增

  × 4 个页面 × 4 条断言 = 112 项，跑一遍 20 秒左右。
  断言是"可证伪"的：无横向溢出、顶栏不压页签、品牌单行、无卡片越界。

## v4.1 · 2026-10-27（同日修订）

用户更正两处环境信息后复测并修复。

### 修复

11. **4.0 的 `auth` 放错位置（严重，阻断整个 4.0 接入）**
    原实现把 `sessionid` 写进 `params.auth`。Zabbix 要求 `auth` 是 **JSON-RPC 请求对象的根级字段**，
    与 `params` 平级。放错时上游返回 `Invalid params / Not authorised.`，
    而 `user.login` 明明是成功的 —— 极易误判成「账号没有 API 权限」。
    现在：`_post()` 直接构造完整信封 `{jsonrpc, method, params, id, auth}`。
    此 bug 在 4.0 凭据未通时**从未被执行到**，属于"链路一通就暴露"的潜伏缺陷。

12. **主机详情横幅文案**：`查完无结果` 分支丢了"最近一次数据"这个标签，
    读起来像"整台主机没有历史"。现在统一为 `· 最近一次数据 未找到` /
    `· 最近一次数据 前 10 项均未找到`，与"查到时间"的分支保持同一句式。

13. **截图脚本等到位**：`tests/shots.mjs` 原先只等标题出现就截图，
    4.0 首屏较慢（157 主机 + 522 监控项）会截到"读取 history.get…"的中间态。
    现在等 `#chartBox canvas` 出现；新增 `FULL=0` 只截首屏，便于看顶部细节。
