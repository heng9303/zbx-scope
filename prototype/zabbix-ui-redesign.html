必须提前知道的 8 个坑

  1. 返回值全是字符串。severity: "5"，acknowledged: "0"。JS 里必须 Number() 后再比较，否则 "0" 是真值。
  2. 没有 offset 分页。只有 limit，深分页要用 eventid_till 做游标。
  3. problem.get 没有 host。必须用 objectid（=triggerid）二次查，注意批量避免 N+1。
  4. history 会过期。默认保留 90 天，超期取不到；长周期必须切 trend.get。
  5. history 数据量大。24h × 1min 就是 1440 点/指标，需降采样或用 trend。
  6. 统计口径要统一。默认排除维护期抑制的问题，图表与列表口径不一致会被质疑。
  7. 认证方式变了。7.0 已弃用 auth 字段，用 Authorization: Bearer 或同域 zbx_session cookie。
  8. 权限在 API 层。独立 UI 不做前端元素级权限，但 API 会按登录用户过滤数据，不会越权。

数据源设置

同域部署可填相对路径，直接复用浏览器里的 zbx_session；跨域需填完整 URL。
在 Zabbix「用户设置 → API tokens」创建。7.0 起用 Authorization: Bearer 传递。
为什么连不上：
  • 直接双击 file:// 打开时，浏览器会拦截跨域请求，必须用 http(s) 访问。
  • 跨域时需 7.0.7+（支持 Authorization 头的 CORS）；更早版本请走同域或加反向代理。
  • Apache 默认不转发 Authorization 头，需加 SetEnvIf Authorization "(.*)" HTTP_AUTHORIZATION=$1。
