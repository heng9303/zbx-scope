只读保证

—
1
浏览器不持有凭据。Token 或 4.0 只读账号只存在于本机代理进程（real/config.json），页面通过同源代理取数。
2
出口白名单：只放行 — 个读取方法（.get / apiinfo.version）。其余方法在本地直接拒绝，请求不会发往 Zabbix。
3
已拦截写操作：0 次；已转发只读请求 0 次。
4
每次转发写入 real/audit.jsonl，可事后核对。

只读白名单

—
白名单之外的任何方法（create / update / delete / acknowledge / execute / import） 都会在代理层被拒绝，不会发往 Zabbix。
